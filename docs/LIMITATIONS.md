# 미구현 기능 및 한계

거짓으로 "완료"라고 표시하지 않기 위해, 구현하지 못했거나 모델로 대체한 부분을 모두 적습니다.

## 데이터 한계 (가장 중요)
1. **19.2 라이브 데이터 없음** — 19.2는 2026-12-15 예정. 현재 Set 19 데이터는 Dev Drop 사전 공개본이며 PBE·라이브에서 바뀔 수 있음.
2. **수치 없음** — 특성 단계별 %·스탯, 증강 수치, 챔피언 스탯/스킬 수치는 Riot이 공개하지 않아 수록하지 않음. 특성은 "단계(브레이크포인트)"만 계산.
3. **경제 규칙·상점 확률·풀 크기·아이템 조합표는 Set 18 값** — Set 19에서 바뀌면 교체 필요(`carryover` 표시).
4. **7코스트 4명**: 상점 확률·풀 크기 비공개 → 시뮬레이터 상점에서 제외(팀 빌더·정찰에서는 사용 가능).
5. **한국어 명칭**: 특성 42개·증강 330개의 공식 한국어 이름 미확인 → 영문 원문 표시. 증강 설명도 영문 원문.
6. **해금 조건**: 원문 문장만 있고 필요한 수치(예: "required number of items")는 비공개 → 시뮬레이터에서 자동 판정하지 않고 사용자가 "해금 처리".
7. 회전초밥 라운드의 수입·XP 지급 여부, Rock 단계 기준, 레벨 1 상점 확률은 출처가 불명확해 가정값 사용(데이터에 표시, 수정 가능).

## 시뮬레이터 모델 한계 (UI에 "training-model" 표시)
- **전투 시뮬레이션이 아님**: 승패는 보드 가치(코스트·별·아이템·활성 특성 수) 대 스테이지별 표준 상대의 비교로 확률을 추정. 챔피언 스킬·배치·상성은 반영하지 않음. 실제 결과를 재현하려면 "수동 입력" 모드 사용.
- 상대 7명은 봇: 체력 감소·탈락과 풀 점유만 모델링(실제 보드 없음). 회전초밥 선택 순서(체력 낮은 순) 미구현.
- PvE 전리품, 회전초밥 구성, 증강 등급은 공개 확률이 없어 단순 무작위.
- 증강·특성의 실제 효과(골드·아이템·전투력 등)는 자동 적용하지 않음 → "수동 보정"으로 반영.
- 재료를 아이템 칸에서 직접 합치는 기능은 훈련 편의 기능(실제 게임은 유닛에 장착해 조합). 장착한 아이템 해제(자석 등) 미구현 — 판매 시 반환만 구현.

## 정찰 · 증강 분석 한계
- 위험 점수·적합도는 역할 데이터와 키워드 기반 **휴리스틱**. 암살자 진입 대상, 스킬 범위, 증강 수치를 반영하지 않음.
- 상대 보드는 직접 입력(게임 클라이언트 연동·자동 정찰 없음 — 서버·API 키 금지 원칙).

## 기타
- 터치 기기에서 HTML5 드래그는 동작하지 않음 → 클릭(탭) 선택 후 칸 탭으로 이동하는 방식으로 대체(테스트됨).
- 자동 테스트는 Chromium에서만 수행. 실제 Chromebook·모바일 기기, Firefox/Safari 수동 테스트는 하지 못함.
- CommunityDragon 변환기는 현재 형식 기준으로 작성·축소 샘플로 검증. Set 19 파일이 공개되면 증강 등급 추정(아이콘/이름 패턴)과 해금 정보는 수동 확인 필요.
- 브라우저 저장소이므로 브라우저 데이터 삭제 시 기록이 사라짐 → 정기적으로 "전체 기록 내보내기" 권장(일일 자동 백업은 같은 브라우저 IndexedDB에만 저장됨).
- 다국어(영문 UI) 미지원.
